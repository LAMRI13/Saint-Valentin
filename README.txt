# Site Saint-Valentin (moderne) + musique + 3 cases à gratter

## Photos
Remplace les images dans `assets/` en gardant les noms :
- hero.jpg
- pic1.jpg
- pic2.jpg
- reveal1.jpg
- reveal2.jpg
- reveal3.jpg

## Musique
Le site lit `assets/music.mp3`.
➡️ Mets un fichier audio que tu as le droit d’utiliser (je ne peux pas fournir une chanson protégée par droits d’auteur).
Sur mobile, la musique démarre après un tap (bouton Play).

## Surprise
Dans la section "Surprise", tu as 3 cases à gratter indépendantes :
- Case 1 -> reveal1.jpg
- Case 2 -> reveal2.jpg
- Case 3 -> reveal3.jpg

## Mise en ligne + QR
GitHub Pages ou Netlify, puis QR code vers l'URL.
